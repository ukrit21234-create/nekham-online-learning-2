# ห้องเรียนออนไลน์ โรงเรียนเนกขัมวิทยา (ต้นแบบ)

เว็บไซต์แบบ Static HTML/CSS/JavaScript รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์ เหมาะสำหรับเริ่มต้นนำขึ้น GitHub Pages

## สิ่งที่มีในต้นแบบ
- หน้าแรกสำหรับโรงเรียนเนกขัมวิทยา
- ตัวกรองรายวิชาตามระดับชั้น ม.1–ม.6 และการศึกษาที่ยืดหยุ่น
- ค้นหารายวิชาตัวอย่าง
- หน้าต่างเข้าสู่ระบบรหัสนักเรียน และแท็บแนวคิดสำหรับ Google
- จุดเริ่มต้นหน้ารายละเอียดรายวิชาและส่งงาน
- Responsive layout และคีย์ Escape/คลิกพื้นหลังเพื่อปิดหน้าต่าง

## ข้อจำกัดสำคัญ
ต้นแบบนี้ **ยังไม่ใช่ระบบใช้งานจริง** ไม่มีฐานข้อมูล ไม่ตรวจสอบตัวตน ไม่บันทึกงาน และไม่ส่งไฟล์ขึ้นเซิร์ฟเวอร์ ฟอร์มเข้าสู่ระบบถูกตั้งใจให้แสดงข้อความสาธิตโดยไม่ส่งหรือเก็บรหัสผ่าน อย่าใช้รหัสผ่านจริง

## ทดลองเปิด
เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือใช้ Live Server ใน VS Code

## เผยแพร่ด้วย GitHub Pages
1. สร้าง repository ใหม่ใน GitHub เช่น `nekham-online-learning`
2. อัปโหลดไฟล์ `index.html`, `styles.css`, `app.js` และ `README.md` ไปไว้ที่ root ของ branch หลัก
3. เปิด **Settings → Pages**
4. เลือก **Deploy from a branch** แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)` จากนั้นบันทึก
5. รอให้ GitHub Pages สร้างเว็บไซต์ แล้วเปิด URL ที่ GitHub แสดงในหน้า Pages

## ขั้นตอนต่อไปเพื่อระบบจริง
1. ออกแบบฐานข้อมูลนักเรียน ชั้นเรียน รายวิชา งานส่ง และผลคะแนน
2. เชื่อมระบบยืนยันตัวตน เช่น Firebase Authentication/Supabase Auth หรือ backend ที่โรงเรียนดูแล โดยรหัสผ่านต้องถูกจัดการฝั่งเซิร์ฟเวอร์อย่างปลอดภัย
3. เพิ่มพื้นที่อัปโหลดไฟล์และนโยบายชนิด/ขนาดไฟล์
4. สร้างสิทธิ์นักเรียน ครู ผู้ดูแลระบบ และรายงานการส่งงาน
5. ทดสอบสิทธิ์เข้าถึงและการคุ้มครองข้อมูลส่วนบุคคลก่อนใช้กับนักเรียนจริง

## โครงสร้างไฟล์
- `index.html` — โครงหน้าเว็บและข้อความภาษาไทย
- `styles.css` — การออกแบบและ responsive styles
- `app.js` — ตัวกรองรายวิชาและพฤติกรรมของหน้าต่างสาธิต
